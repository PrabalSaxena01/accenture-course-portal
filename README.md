# Accenture Mock Test Series — Placement Portal & Complete Question Bank

A modern, responsive, and searchable course exploration platform built with **React** and **Vite**. This web application provides a structured syllabus, module navigation, interactive MCQ practice engine, cognitive game simulators, educational walkthroughs, and an exhaustive **1,841-Question Archive** for the **Accenture Mock Test Series** from KN Academy.

🌐 **Live Web Application**: [prabalsaxena01.github.io/accenture-course-portal](https://prabalsaxena01.github.io/accenture-course-portal/)  
📂 **GitHub Repository**: [github.com/PrabalSaxena01/accenture-course-portal](https://github.com/PrabalSaxena01/accenture-course-portal)  
📖 **Question Bank Repository**: [`questions/`](./questions/README.md) (All 21 modules with full questions, options, answers, and explanations in Markdown)

## 🌟 Highlights & Features

- **⚡ 1,841 Verified Questions with 4 Options (A, B, C, D)**:
  - Every single question includes authentic multiple-choice options with verified solutions and explanations.
  - Interactive test mode: Click any option to test your knowledge with real-time green/red visual grading and feedback.
- **📸 150 Vector SVG Visual Diagrams & Blueprints**:
  - Embedded vector diagrams for visual questions: Water/Mirror reflections, 3×3 matrix arithmetic tables, Paper Folding & Unfolding, 90° Clockwise Rotations, CSS3 geometry boxes, Excel 8-cell merge grids, and Host crossover topologies.
- **🎮 Cognitive Game Simulators (Module 04)**:
  - Interactive **Path Finder** (5×5 labyrinth maze pathfinder with obstacle navigation).
  - Interactive **Memory Matrix** (4×4 flash memory retention grid).
- **⚡ Fast Search & Multi-Level Filtering**:
  - Instant search across all 1,841 questions, options, code solutions, and module syllabi.
  - Filter chips for *All Questions*, *Visual Diagrams*, *Practice MCQs*, and *Coding Sets*.
- **📊 Real-Time Progress Tracking**:
  - Interactive lesson completion checkboxes persisted locally in your browser (`localStorage`).
  - Visual progress bar calculating real-time percentage and completed fractions.
- **📚 100% Inspected Course Hierarchy**:
  - **21 Modules** and **206 Learning Items** fully accounted for with zero omitted sections.
- **🗓️ 14-Day Placement Sprint Roadmap**:
  - Step-by-step preparation plan targeting Cognitive Game Tests, Technical MCQs, Pseudocode, Algorithms, and AI Voice Communication.

## 🚀 Installation & Local Development

### Prerequisites
- Node.js (v18.0.0 or higher recommended)
- npm or yarn

### Steps
1. **Clone the repository**:
   ```bash
   git clone https://github.com/PrabalSaxena01/accenture-course-portal.git
   cd accenture-course-portal
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```
   Open your browser and navigate to `http://localhost:5173`.

4. **Build for production**:
   ```bash
   npm run build
   ```
   Production assets will be generated in the `dist/` directory.
